Hierarchical reorder and reparent use the same **`MoveIntent`** as flat lists. The optional **`@kamod-ch/dnd/tree`** subpath ships pure helpers; your app still owns node data and rendering.

## Install path

```bash
pnpm add @kamod-ch/dnd @preact/signals preact
```

```ts
import { DndProvider, type MoveIntent } from "@kamod-ch/dnd";
import { useSortable, useSortableContainer } from "@kamod-ch/dnd/sortable";
import {
  applyTreeMove,
  DEFAULT_ROOT_CONTAINER_ID,
  parentOf,
  validateTreeMove,
  type TreeNode,
  type TreeState,
} from "@kamod-ch/dnd/tree";
```

## Container-per-parent

Each parent’s ordered children are a **container id** (the parent node id, or `DEFAULT_ROOT_CONTAINER_ID` for top-level roots). Register:

- **`useSortableContainer`** on the child **list** element (`data-testid="children-{parentId}"` in the spike).
- **`useSortable`** on the **row header** only — do not wrap nested lists in the same item drop target, or pointer hits will miss item edges.

In `onMove`, run `validateTreeMove` then `applyTreeMove` and replace your tree state when the result is `ok`.

## Engine behavior

Nested child lists register container drop targets. The pragmatic engine picks the active target with **`pickActiveDropTarget`** (container vs item precedence) instead of always using `dropTargets[0]`. Flat Kanban and editor examples keep item-edge reordering.

## Example

`examples/tree` is the browser reference. It uses only `@kamod-ch/dnd`, `@kamod-ch/dnd/sortable`, and `@kamod-ch/dnd/tree`: recursive rows, an empty child list, cycle rejection, keyboard indent/outdent, human labels, and focus after an accepted reparent.

Collapsed parents stay application state. The example expands a collapsed parent after the pointer rests on its row for 900ms (`COLLAPSED_HOVER_EXPAND_MS`). Leaving the row, dropping, unmounting, or changing the drag target clears that timer. `reducedMotion` on `DndProvider` expands on the next rest with no delay. This recipe is not a core API.

Flattened-row trees and virtualized trees are unsupported.

```bash
pnpm --filter @kamod-dnd/example-tree dev
```

## Limitations

`@kamod-ch/dnd/tree` stays **experimental**. Chromium, Firefox, and WebKit cover the example, including focus and labels. VoiceOver, NVDA, iOS Safari, and Android Chrome are not certified. See [`docs/tree-evaluation.md`](https://github.com/kamod-ch/kamod-dnd/blob/main/docs/tree-evaluation.md) and [`docs/a11y-manual-checklist.md`](https://github.com/kamod-ch/kamod-dnd/blob/main/docs/a11y-manual-checklist.md).
