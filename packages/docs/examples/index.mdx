Each card runs the real `@kamod-ch/dnd` package from this workspace — not a mock. Drag from the **⠿** handle; use the keyboard buttons on Kanban and editor demos to move items without a pointer.

## Sortable list

Single container, reorder by index. Target index is computed **after removing** the item from the source list.
