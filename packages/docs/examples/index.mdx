Each card runs the real `@kamod-ch/dnd` package from this workspace — not a mock. Drag from the **⠿** handle. On sortable rows, **Space/Enter** picks up and drops; **arrow keys** move within the same container. Kanban and editor demos also expose keyboard buttons for cross-container moves.

## Sortable list

Single container, reorder by index. Target index is computed **after removing** the item from the source list.
